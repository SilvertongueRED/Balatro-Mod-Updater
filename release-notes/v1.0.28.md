Delete old backups, one at a time or several at once.

**New**
- In a mod's **Backups** window every backup has a red **Delete** button and a tick box. **Delete Selected (n)** above them deletes all the ticked ones.
- You are asked to confirm first. The files go to the Windows **Recycle Bin**, never a permanent delete, and the list opens again afterwards (or the Backups tab when no backup is left).
- Works with mouse, keyboard and controller. Covers mod backups and the Steamodded / Lovely copies, not the saved game copies.
- `delete_backups.ps1` does the moving. It only touches `.zip` and `.dll` files inside the backup folder.

The README has screenshots of the new buttons and the confirmation.
