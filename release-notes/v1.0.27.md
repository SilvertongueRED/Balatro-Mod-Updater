Fixes, a big speed-up and a clearer Fork Finder.

**Fixes**
- Steam no longer shows Balatro as running after you quit during an update check or fork scan. Waiting on the internet is cut the moment the game closes, a step that writes files gets at most 20 seconds, and any git process the check started is ended with it. `quit_watch.log` in the Updater folder records each quit.
- The background check now ends itself as soon as it is done. Since 1.0.26 it kept running until the game closed, so the game only noticed through its 5 minute timeout, and **Unpin** stayed on "Checking for a newer version..." for good.

**Faster**
- **Scan Now** only scans forks. It no longer runs the whole mod update first. Mods are still updated at every launch and by **Check for updates now**.
- With a GitHub token, a repeat fork scan checks GitHub up to 8 answers at once. On a list of about 60 mods a scan went from minutes to about 14 seconds, with results exactly as fresh as before.
- The update check fetches up to 6 git mods at once.
- Backups and unzipping are much faster, and the Updater's own backup no longer zips its caches (one self-update took over 13 minutes before).

**Fork Finder**
- With nothing to list it says "No newer forks found on last scan (MM-DD-YY)." While a scan runs it adds a waving **NEWER SCAN IN PROGRESS**, and the "Scanning for forks..." line waves too. Other messages stay still.
- The **Open fork page / Release** button is a little wider with bigger text that still fits.

The README now has screenshots of every tab and step-by-step pictures for the GitHub token and Nexus key.
